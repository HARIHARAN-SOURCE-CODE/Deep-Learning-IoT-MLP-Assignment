# Deep-Learning-IoT-MLP-Assignment
Deep Learning and IoT assignment implementing a Multi-Layer Perceptron (MLP) for IoT sensor data classification. The project compares models with 1, 2, and 3 hidden layers and evaluates different optimizers, including SGD, SGD with Momentum, Adam, and RMSprop, using accuracy, precision, recall F1-score confusion matrices, and classification reports
